# Vertex AI in Firebase for Android Example

An example project for using the **Firebase Vertex AI SDK** in an Android app.  
This hands-on sample is designed for developers who want to learn about [Vertex AI](https://cloud.google.com/vertex-ai) and [Gemini models](https://firebase.google.com/docs/vertex-ai) in Firebase.

---

## 🛠 Development Environment

- Java 11  
- Kotlin  
- Jetpack Compose  
- Android Studio **Meerkat | 2024.3.1**

---

## 📚 Reference Documentation

- [Vertex AI Overview (Google Cloud)](https://cloud.google.com/vertex-ai)  
- [Vertex AI in Firebase Official Docs](https://firebase.google.com/docs/vertex-ai)  
- [Firebase Vertex AI Quickstart for Android](https://firebase.google.com/docs/vertex-ai/get-started?platform=android)  
- [Image Generation (Imagen) Sample](https://firebase.google.com/docs/vertex-ai/generate-images-imagen?platform=android)

---

## ⚠️ Notice

This sample project does **not** include the `google-services.json` file, so it **will not build immediately**.  
Register your Android app in the Firebase console and add the `google-services.json` file by following:

- [Firebase Android Project Setup Guide](https://firebase.google.com/docs/android/setup)

---

## 📦 Project Purpose

This sample demonstrates how to integrate Vertex AI features into your Android app via Firebase, enabling you to call Gemini models and practice text/image generation directly from your app.
