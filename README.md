# Vertex AI in Firebase for Android Example

안드로이드 앱에서 **Firebase Vertex AI SDK**를 사용하는 예제 프로젝트입니다.  
[Vertex AI](https://cloud.google.com/vertex-ai?hl=ko) 및 [Gemini 모델](https://firebase.google.com/docs/vertex-ai?hl=ko)에 대해 학습하고 싶은 개발자를 위한 실습 예제로 구성되어 있습니다.

---

## 🛠 개발 환경

- Java 11  
- Kotlin  
- Jetpack Compose  
- Android Studio **Meerkat | 2024.3.1**

---

---

## ⚠️ 주의사항

이 예제 프로젝트에는 `google-services.json` 파일이 포함되어 있지 않기 때문에 **바로 빌드되지 않습니다**.  
Firebase 콘솔에서 Android 앱을 등록하고, 아래 가이드를 참고해 `google-services.json` 파일을 추가하세요.

- [Firebase Android 프로젝트 설정 방법](https://firebase.google.com/docs/android/setup?hl=ko)

---

## 📦 프로젝트 목적

Firebase에 통합된 Vertex AI 기능을 통해 Android 앱 내에서 Gemini 모델을 호출하거나, 텍스트/이미지 생성을 실습할 수 있도록 돕기 위한 목적의 샘플입니다.
